Create a new day directory for Advent of Code 2025.

The user will provide a day number (1-25).

Steps:
1. Create the directory `2025/day-{number}` by copying from `2025/template`
2. Show the user which files were created
3. Let them know they can now add their puzzle input to `2025/day-{number}/input` and example to `2025/day-{number}/example-one`
