---

Run the Advent of Code 2025 interactive runner.

Execute `cd 2025 && ruby runner.rb` to start the interactive menu that lets the user select which day to run.

The runner will:
- Auto-generate files for new days
- Run part one first, then part two after part one passes
- Watch files for changes and auto-reload
- Track which parts are solved
