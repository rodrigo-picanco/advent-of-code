Help the user solve their current Advent of Code puzzle.

The user will tell you which day and part they're working on.

Steps:
1. Read the puzzle code in `2025/day-{number}/part-{one|two}.rb`
2. Read the example input and expected output
3. Help debug or implement the solution
4. The solution should implement the `parse` and `run` methods in the Puzzle class
5. Remember: `assert` tests with example input, `solve` runs with real input
